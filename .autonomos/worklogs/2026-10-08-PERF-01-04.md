## Key decisions and why

- Version-keyed caches (not invalidation): keys embed every input
  that can change the output, so staleness is impossible; verified
  byte-identical hit/miss, gzip round-trip, invalidation on POST.
- `maskCsrf` re-pads per request: keys use `session._csrf_token`.
- Jobs queue durability relaxed to best-effort (NORMAL), matching
  Rust's in-memory queues; backup uses the online API (safe).
- Cable trades per-message re-auth for prune-on-revoke + sweep
  (Rust parity); tests pin the new contract.
- PASSIVE never truncates: RESTART added after measuring 220MB WAL.
